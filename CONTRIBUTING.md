# Contributing

Contributions that make field onboarding clearer, more reproducible or better supported by evidence are welcome.

1. Describe the research-onboarding problem and include a small realistic input.
2. Keep new references linked from `SKILL.md` or the relevant workflow.
3. Keep datasets and demos dated; document source coverage and exclusions.
4. Preserve primary-source attribution and distinguish evidence from proposals.
5. Run `python3 scripts/validate.py` and `python3 -m unittest discover -s tests`.
6. Render and inspect any changed slide. Include a preview and explain material differences.

Do not commit credentials, private papers, local machine paths, generated temporary folders or unlicensed copies of third-party works. Link to public papers when redistribution rights are unclear. Do not modify the retained reference casually; supply a new version with provenance and an updated manifest when necessary.
